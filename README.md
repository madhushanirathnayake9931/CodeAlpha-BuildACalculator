# Calculator Web Application

A simple and attractive calculator web application built using **HTML**, **CSS**, and **JavaScript**. It can perform basic arithmetic operations such as addition, subtraction, multiplication, division, percentage calculation, decimal input, clear, and delete/backspace.

## Preview

This project contains a modern calculator interface with:

- A clean and colorful UI design
- Number buttons from 0–9
- Addition, subtraction, multiplication, and division operations
- Percentage (`%`) calculation
- Decimal (`.`) input
- Clear (`C`) button
- Backspace/delete button
- Equal (`=`) button to display the final answer
- Responsive calculator layout
- Decorative educational-themed images/background

## Technologies Used

- **HTML5** – Used to create the calculator structure
- **CSS3** – Used for styling, colors, layout, buttons, and responsive design
- **JavaScript** – Used to implement calculator functionality and calculations

## Features

| Feature | Description |
|---|---|
| Number Input | Users can enter numbers from 0 to 9 |
| Addition | Adds two or more values |
| Subtraction | Subtracts values |
| Multiplication | Multiplies values |
| Division | Divides values |
| Percentage | Calculates percentage values |
| Decimal Support | Allows decimal number calculations |
| Clear Button | Clears the calculator display |
| Delete Button | Removes the last entered character |
| Equal Button | Calculates and displays the result |

## How to Run the Project

1. Download or clone this repository.

bash
git clone [https://github.com/madhushanirathnayake9931/CodeAlpha-BuildACalculator.git]

2. Open the project folder.

3. Open the `index.html` file in a web browser.

Or, if you use VS Code:

1. Open the project in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The calculator will open in your browser.

## How to Use

1. Click the number buttons to enter values.
2. Click an operator such as `+`, `−`, `×`, or `÷`.
3. Enter the next number.
4. Click `=` to view the answer.
5. Click `C` to clear the whole display.
6. Click the backspace button to remove the last entered digit or operator.
7. Use `.` when entering decimal values.
8. Use `%` for percentage calculations.
